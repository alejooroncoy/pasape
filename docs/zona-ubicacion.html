Cómo lo resuelven Posh / Eventbrite

  • Posh: las mesas/boxes son tarjetas; el área (“Main Floor”, “Mezzanine”) es un tag con pin dentro de la tarjeta, no un encabezado. La zona es un atributo, no una sección.
  • Eventbrite: lista plana de entradas. La zona/sección solo aparece cuando hay asientos reservados (y ahí vive sobre un mapa, no como título).
  • Para el organizador: la ubicación queda opcional (“¿Dónde está? — ej. Platinum, Terraza”). Si la deja vacía, el comprador no ve ningún pin.
